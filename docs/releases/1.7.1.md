# codingStandard 1.7.1

## Release focus

Operational validation for the 1.7.0 ML/DL and Colab architecture.

## Included

- Added explicit agent-routing validation scenarios for generic PyTorch training, LLM QLoRA, Vision detection, and Colab LLM training.
- Added a Colab runtime validator that reports the active kernel, operating system, accelerator, RAM, disk, and optional durable-storage writability.
- Added a clean-runtime Colab notebook covering runtime reporting, routing validation, PyTorch smoke execution, and checkpoint/restore.
- Added the ML/DL runtime validation guide.
- Extended Linux and macOS CI to validate the new routing, Colab utility, and notebook JSON assets.
- Bumped the development version to `1.7.1`.

## Validation target

A successful 1.7.1 validation confirms that the installed policy can be routed into the expected ML/LLM/Vision/Colab resource chain and that a representative ephemeral-runtime workflow can measure resources and restore a checkpoint.

Live Colab hardware execution remains an external validation step because GitHub-hosted CI does not provide a stable Colab runtime.
