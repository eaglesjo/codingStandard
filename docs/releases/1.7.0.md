# codingStandard 1.7.0

## Release focus

ML/DL development lifecycle, multi-agent routing, and Google Colab execution support.

## Included

- Added `domains/ml/` for cross-domain machine-learning and deep-learning lifecycle policies.
- Added shared Skills for data validation, experiment design, evaluation, training, distributed training, hyperparameter optimization, inference, and MLOps.
- Added LLM Skills for fine-tuning, PEFT, quantization, and RAG.
- Added `platform/colab/` for ephemeral hosted-runtime detection, durable checkpointing, recovery, and resume-oriented execution.
- Normalized AI coding-agent adapters to the canonical `core/common` + `domains/*` routing model.
- Extended Bash and Windows PowerShell installers for ML and Colab domains.
- Extended repository validation, localization parity, installer integration tests, and Colab notebook validation.
- Updated Korean localized runtime and Agent/Skill resources.
- Updated the common dependency contract and stable PyTorch/torchvision baseline to 2.13.0/0.28.0.
- Bumped the development/release version to `1.7.0`.

## Validation

The release candidate passed:

- Ubuntu 24.04 repository, environment, installer, LLM CPU smoke, and Vision CPU smoke validation.
- macOS repository, environment, and installer validation.
- Windows PowerShell 5.1 and PowerShell 7 installer integration validation.

Google Colab is covered by the repository's clean-runtime validation notebook and explicit Colab execution policy. A live Colab GPU session is intentionally not part of the GitHub-hosted CI contract.

## Migration

Use the canonical paths documented in `AGENTS.md` and `docs/development/REPOSITORY_STRUCTURE.md`. Legacy `COMMON/`, `LLM/`, `VISION/`, and old top-level validation/installer paths are obsolete.
