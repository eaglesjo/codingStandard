# codingStandard 1.8.0

## Purpose

Add resource-aware LLM fine-tuning validation for PEFT/QLoRA strategy selection.

## Changes

- Add a network-independent LLM QLoRA strategy integration smoke.
- Validate low-VRAM GPU routing to 4-bit QLoRA, mid-range GPU routing to LoRA, and CPU fallback behavior.
- Validate LoRA adapter parameter-efficiency calculations.
- Probe optional `transformers`, `peft`, and `bitsandbytes` availability without making them mandatory CI dependencies.
- Preserve the rule that quantization backends must be validated against the actual runtime and hardware.

## Validation scope

This test validates strategy selection and adapter math. It does not claim a real model was loaded or fine-tuned with bitsandbytes/PEFT in CI. Hardware-specific QLoRA execution remains an optional Colab/runtime validation path.
