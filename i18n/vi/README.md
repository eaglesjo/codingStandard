# codingStandard — Tiếng Việt

Chào mừng đến với codingStandard. Tài liệu này mô tả các tiêu chuẩn phát triển, kiểm tra và quy tắc runtime của dự án.

Tài nguyên runtime hiện sử dụng tiếng Anh làm ngôn ngữ dự phòng. Bản địa hóa runtime đầy đủ bằng tiếng Việt sẽ được bổ sung sau khi xác thực các tài nguyên cốt lõi.
