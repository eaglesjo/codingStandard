# codingStandard — Tiếng Việt

Chào mừng đến với codingStandard. Tài liệu này mô tả các tiêu chuẩn phát triển, kiểm tra và quy tắc runtime của dự án.

Tiếng Việt là một trong 20 runtime locale. Tài nguyên runtime được kiểm tra về tính đầy đủ, semantic parity và tính nhất quán giữa runtime với tài liệu; tiếng Anh vẫn là ngôn ngữ dự phòng được xác định.
