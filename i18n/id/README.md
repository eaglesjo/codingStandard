# codingStandard — Bahasa Indonesia

Selamat datang di codingStandard. Dokumentasi ini menjelaskan standar pengembangan, validasi, dan aturan runtime proyek.

Bahasa Indonesia adalah salah satu dari 20 runtime locale. Sumber daya runtime divalidasi untuk kelengkapan, semantic parity, dan konsistensi runtime/dokumentasi; bahasa Inggris tetap menjadi fallback yang ditetapkan.
