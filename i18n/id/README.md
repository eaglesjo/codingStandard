# codingStandard — Bahasa Indonesia

Sumber daya runtime saat ini menggunakan bahasa Inggris sebagai fallback. Lokalisasi runtime lengkap dalam bahasa Indonesia akan ditambahkan setelah sumber daya inti divalidasi.
