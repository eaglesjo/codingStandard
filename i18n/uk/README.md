# codingStandard — Українська

Ласкаво просимо до codingStandard. У цій документації описано стандарти розробки, перевірки та правила виконання проєкту.

Українська є однією з 20 runtime locale. Ресурси runtime перевіряються на повноту, семантичну паритетність і узгодженість runtime з документацією; англійська залишається визначеною резервною мовою.
