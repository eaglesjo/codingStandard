# codingStandard — Українська

Ласкаво просимо до codingStandard. У цій документації описано стандарти розробки, перевірки та правила виконання проєкту.

Ресурси runtime наразі використовують англійську як резервну мову. Повна українська локалізація runtime буде додана після перевірки основних ресурсів.
