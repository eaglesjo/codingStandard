# Загальні правила для AI-агентів

1. Прочитайте та виконуйте інструкції репозиторію.
2. Дотримуйтеся наявної архітектури та політик.
3. Перед зміною поведінки перевірте відповідний код і tests.
4. Для змін поведінки додайте або оновіть tests.
5. Приховуйте платформозалежні деталі за abstraction.
6. Не комітьте secrets або credentials.
7. Використовуйте network access лише за явної потреби.
8. Вважайте реальне execution environment source of truth.
9. Надавайте перевагу reproducible validation.
10. Після змін запускайте validation і звітуйте про результат.

## Цикл роботи

```text
Inspect → Plan → Change → Validate → Review → Report
```

Перевіряйте memory і runtime перед припущеннями про обладнання. Для довгих задач перевіряйте early stopping і checkpoint.
