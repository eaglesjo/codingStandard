# codingStandard — Polski

Witamy w codingStandard. Ta dokumentacja opisuje standardy programistyczne, walidację i zasady działania projektu.

Polski jest jednym z 20 runtime locale. Zasoby runtime są sprawdzane pod kątem kompletności, parytetu semantycznego i spójności runtime/dokumentacji; angielski pozostaje zdefiniowanym językiem fallback.
