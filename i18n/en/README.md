# English LLM Coding Standard

This directory contains the English language resources for the AI coding standard.

Core documents:

- `AGENT.md` — full AI coding-agent rules
- `SKILL.md` — full LLM/Jupyter/ML execution workflow
- `ENVIRONMENT.md` — full environment detection and optimization rules

The runtime profiler `LLM/environment.py` is language-neutral and is shared by both language installations.

The installer currently uses the repository-root English files as the default English source and `i18n/ko/` for the Korean source. The English files in this directory mirror the localized standard so both language sets can be maintained consistently.
