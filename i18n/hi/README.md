# codingStandard — हिन्दी

codingStandard में आपका स्वागत है। यह दस्तावेज़ परियोजना के विकास मानकों, सत्यापन और रनटाइम नियमों का वर्णन करता है।

हिन्दी 20 runtime locales में से एक है। रनटाइम संसाधनों की पूर्णता, semantic parity और runtime/documentation consistency की जाँच की जाती है; अंग्रेज़ी परिभाषित fallback भाषा बनी रहती है।
