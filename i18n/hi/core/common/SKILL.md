# कौशल और कार्यप्रवाह

किसी कौशल या validation workflow को चलाते समय:

1. उद्देश्य और scope स्पष्ट करें।
2. वर्तमान repository state जाँचें।
3. canonical policy और संबंधित domain दस्तावेज़ देखें।
4. छोटे, traceable बदलाव करें।
5. tests और validation को दोहराने योग्य रखें।
6. environment और उपलब्ध memory के अनुसार runtime configuration चुनें।
7. आवश्यकता होने पर early stopping का उपयोग करें।
8. पुनरारंभ योग्य कार्यों के लिए checkpoint सुरक्षित रखें।
9. failure को छिपाएँ नहीं; कारण और प्रभाव स्पष्ट करें।
10. अंतिम परिणाम और शेष जोखिम रिपोर्ट करें।
