# Règles communes de l’environnement

- Détectez d’abord l’environnement réel et ses capacités.
- Ne faites aucune hypothèse fixe sur le système d’exploitation, le CPU, la RAM, le GPU ou l’IDE.
- Mesurez les ressources disponibles avant les charges intensives.
- Préférez une configuration explicite, centralisée et reproductible.
- Documentez les informations pertinentes sur l’environnement, les ressources et les artefacts.
- Gérez explicitement et de manière sécurisée l’accès réseau et les secrets.
