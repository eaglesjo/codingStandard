# Compétences communes de développement IA

Utilisées pour l’exploration du dépôt, la validation de l’environnement, l’implémentation, les tests, la sécurité et la reproductibilité.

```text
Explorer le dépôt → vérifier le contrat de données → détecter l’environnement → mesurer les ressources → décider de la configuration → concevoir baseline/expérience → smoke test minimal → figer l’environnement → implémenter → évaluer → documenter ressources et artefacts
```

Donnez la priorité aux capacités mesurées, centralisez la configuration et ne répétez pas les configurations connues comme défaillantes. Le cycle ML commun est géré sous `domains/ml/`; LLM/Vision ajoutent uniquement les compétences nécessaires.
