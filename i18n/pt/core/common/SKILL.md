# Competências comuns de desenvolvimento de IA

Usadas para explorar o repositório, validar o ambiente, implementar, testar, proteger e reproduzir resultados.

```text
Explorar repositório → verificar contrato de dados → detetar ambiente → medir recursos → decidir configuração → criar baseline/experiência → smoke test → fixar ambiente → implementar → avaliar → registar recursos e artefactos
```

Dê prioridade às capacidades medidas, centralize a configuração e não repita configurações conhecidas como problemáticas. O ciclo ML comum é gerido em `domains/ml/`; LLM/Vision adicionam apenas as competências necessárias.
