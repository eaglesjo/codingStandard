# Ortam Politikası

Çalışma ortamı değişken olabilir. İşletim sistemi, Python sürümü, CPU, RAM, GPU ve hızlandırıcıları varsaymak yerine tespit edin.

- Kaynakları ölçmeden ağır parametreler seçmeyin.
- CPU tabanlı güvenli bir geri dönüş yolu sağlayın.
- Platforma özgü yolları açıkça ayırın.
- Kurulum ve doğrulama adımlarını yeniden üretilebilir tutun.
- Gizli bilgileri ortam değişkenleri veya güvenli yapılandırma ile sağlayın; depoya yazmayın.
