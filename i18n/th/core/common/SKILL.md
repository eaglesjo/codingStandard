# ทักษะและกระบวนการทำงาน

กำหนดเป้าหมายและ scope ตรวจสอบสถานะ repository และอ่าน policy canonical กับเอกสาร domain ที่เกี่ยวข้อง ทำการเปลี่ยนแปลงเล็กและตรวจสอบย้อนกลับได้ รักษา tests และ validation ให้ทำซ้ำได้ ปรับ runtime ตาม environment และ memory จริง ใช้ early stopping เมื่อเหมาะสมและบันทึก checkpoint สำหรับงานที่ทำต่อได้ รายงานข้อผิดพลาดและผลลัพธ์อย่างชัดเจน
