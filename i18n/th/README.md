# codingStandard — ไทย

ยินดีต้อนรับสู่ codingStandard เอกสารนี้อธิบายมาตรฐานการพัฒนา การตรวจสอบ และกฎการทำงานของโครงการ

ภาษาไทยเป็นหนึ่งใน 20 runtime locale ทรัพยากร runtime ได้รับการตรวจสอบด้านความครบถ้วน ความสอดคล้องเชิงความหมาย และความสอดคล้องระหว่าง runtime กับเอกสาร โดยภาษาอังกฤษยังคงเป็นภาษาสำรองที่กำหนดไว้
