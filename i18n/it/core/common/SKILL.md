# Competenze comuni di sviluppo IA

Usate per esplorazione del repository, validazione dell'ambiente, implementazione, test, sicurezza e riproducibilità.

```text
Esplora repository → verifica contratto dati → rileva ambiente → misura risorse → decidi configurazione → baseline/esperimento → smoke test → blocca ambiente → implementa → valuta → registra risorse e artefatti
```

Dare priorità alle capacità misurate, centralizzare la configurazione e non ripetere configurazioni note come fallimentari. Il ciclo ML comune è gestito in `domains/ml/`; LLM/Vision aggiungono solo le competenze necessarie.
