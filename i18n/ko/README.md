# 한국어 LLM Coding Standard

이 디렉터리는 AI coding standard의 한국어 리소스를 제공합니다.

핵심 문서:

- `AGENT.md` — 전체 AI Agent 개발 규칙
- `SKILL.md` — LLM/Jupyter/ML 실행 절차
- `ENVIRONMENT.md` — 실행환경 확인 및 최적화 규칙
- `README.md` — 한국어 리소스 안내

실행 코드인 `LLM/environment.py`, `LLM/memory_smoke_test.py`, `LLM/experiment.py`는 언어 중립적으로 사용하며 설치기는 필요한 공통 실행 파일을 영어 원본에서 가져옵니다.
