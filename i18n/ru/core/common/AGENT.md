# Общие правила AI Agent

Эти правила применяются ко всем поддерживаемым доменам проекта.

1. Перед изменением кода изучите фактический репозиторий, среду выполнения, зависимости, тесты и ограничения безопасности.
2. Перед выбором настроек, зависящих от ресурсов, обнаружьте и измерьте реальную среду выполнения.
3. Не делайте конкретную машину, ОС, CPU, RAM, GPU, ускоритель или IDE обязательным требованием проекта через hard-code.
4. Размещайте переиспользуемую доменную логику в модулях, а Notebook и скрипты ограничивайте оркестрацией.
5. Используйте явную конфигурацию, метаданные воспроизводимости и детерминированные пути.
6. Храните секреты вне системы контроля версий.
7. Сначала проверяйте изменения минимальным осмысленным тестом, затем запускайте более широкий набор тестов.
8. После проверки среды удаляйте неиспользуемые ветви выполнения и устаревший код, если многоплатформенность не является намеренной.
9. Для длительных задач используйте, где уместно, валидацию, Early Stopping, лучший Checkpoint и Resume.
10. Эксперименты должны определять baseline, контролируемые варианты, seed, метрики и отслеживание ресурсов.

## Стандартный жизненный цикл выполнения

```text
Discover → Detect → Measure → Resolve → Smoke Test → Lock → Implement → Validate → Record
```
