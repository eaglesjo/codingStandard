# codingStandard — العربية

مرحبًا بك في codingStandard. توضح هذه الوثائق معايير التطوير والتحقق وقواعد التشغيل الخاصة بالمشروع.

العربية إحدى لغات runtime العشرين (20). تخضع موارد التشغيل للتحقق من اكتمال الموارد والتكافؤ الدلالي واتساق runtime مع التوثيق، بينما تبقى الإنجليزية لغة الاحتياط المحددة.
