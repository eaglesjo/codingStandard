# قواعد مشتركة لوكلاء الذكاء الاصطناعي

تنطبق هذه القواعد على جميع المجالات المدعومة.

1. افحص المستودع وبيئة التشغيل والاعتماديات والاختبارات ومتطلبات الأمان قبل تعديل الكود.
2. اكتشف البيئة الفعلية وقِسها قبل اختيار المعلمات الحساسة للموارد.
3. لا تفترض الحاجة إلى جهاز أو نظام تشغيل أو CPU أو RAM أو GPU أو مسرّع أو IDE محدد.
4. ضع منطق المجال القابل لإعادة الاستخدام في الوحدات، واجعل الدفاتر والبرامج النصية للتنسيق فقط.
5. استخدم إعدادات صريحة وبيانات قابلية إعادة الإنتاج ومسارات حتمية.
6. أبقِ الأسرار خارج التحكم في الإصدارات.
7. ابدأ بأصغر اختبار ذي معنى ثم نفّذ مجموعة الاختبارات الأوسع.
8. بعد التحقق من البيئة، أزل مسارات التنفيذ غير المستخدمة والكود القديم ما لم يكن دعم المنصات المتعددة مقصوداً.
9. للأحمال الطويلة استخدم التحقق وEarly Stopping وأفضل Checkpoint وResume عند ملاءمتها.
10. يجب أن تحدد التجارب baseline ومتغيرات مضبوطة وseeds ومقاييس وتتبعاً للموارد.

## دورة التنفيذ القياسية

```text
استكشف → اكتشف → قِس → حل → Smoke Test → أصلح → نفّذ → تحقق → وثّق
```
