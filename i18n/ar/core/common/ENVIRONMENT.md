# سياسة البيئة

قد تختلف بيئة التشغيل. اكتشف نظام التشغيل وإصدار Python وCPU وRAM وGPU والمسرّعات بدلاً من افتراضها.

- لا تختَر معاملات ثقيلة قبل قياس الموارد.
- وفّر مسار رجوع آمن يعتمد على CPU.
- اعزل المسارات الخاصة بالمنصة بوضوح.
- اجعل التثبيت والتحقق قابلين لإعادة الإنتاج.
- استخدم متغيرات البيئة أو الإعداد الآمن للأسرار ولا تضعها في المستودع.
