# Capacidades comunes de desarrollo de IA

Se usan para explorar el repositorio, validar el entorno, implementar, probar, asegurar y reproducir resultados.

```text
Explorar repositorio → comprobar contrato de datos → detectar entorno → medir recursos → decidir configuración → diseñar baseline/experimento → smoke test → fijar entorno → implementar → evaluar → registrar recursos y artefactos
```

Da prioridad a las capacidades medidas, centraliza la configuración y no repitas configuraciones conocidas como fallidas. El ciclo ML común se gestiona en `domains/ml/`; LLM/Vision solo añaden las capacidades necesarias.
