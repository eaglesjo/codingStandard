# codingStandard — Nederlands

Welkom bij codingStandard. Deze documentatie beschrijft de ontwikkelstandaarden, validatie en runtime-regels van het project.

Nederlands is een van de 20 runtime locales. Runtimebronnen worden gecontroleerd op volledigheid, semantische pariteit en runtime/documentatie-consistentie; Engels blijft de vastgestelde fallback-taal.
