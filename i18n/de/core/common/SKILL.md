# Gemeinsame KI-Entwicklungsfähigkeiten

Verwendung für Repository-Erkundung, Umgebungsvalidierung, Implementierung, Tests, Sicherheit und Reproduzierbarkeit.

```text
Repository erkunden
→ Datenvertrag prüfen
→ Ausführungsumgebung erkennen
→ Ressourcen messen
→ Einstellungen festlegen
→ Baseline / Experiment entwerfen
→ minimaler Smoke Test
→ Umgebung festlegen
→ Implementieren / Trainieren / Inferenz
→ Bewerten / Vergleichen
→ Reproduzierbarkeit, Ressourcen und Artefakte dokumentieren
```

Gemessene Fähigkeiten haben Vorrang. Destruktive Änderungen werden ausdrücklich durchgeführt. Einstellungen werden zentralisiert und bekannte fehlerhafte Konfigurationen nicht wiederholt. Der gemeinsame ML-Lifecycle wird unter `domains/ml/` verwaltet; LLM/Vision ergänzen nur die benötigten Domänenfähigkeiten.
