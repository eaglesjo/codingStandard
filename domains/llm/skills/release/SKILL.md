# Release Skill

Use for release preparation, packaging, and final project cleanup.

Verify the project from a clean environment where practical. Run tests, lint/type checks, documentation/link checks, and a final clean build or installation test.

Confirm the effective coding-standard version, Git commit, dependency lock state, environment profile, and generated artifacts. Do not publish secrets or local machine-specific paths.

For notebooks or models, verify reproducibility metadata, checkpoint availability, and that no temporary/debug code remains.
