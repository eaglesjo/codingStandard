# ML / Deep Learning Skills

Load only the Skills relevant to the task.

| Skill | Use when |
| --- | --- |
| `data` | validating datasets, splits, leakage, labels, preprocessing |
| `experiment` | designing baselines, controlled variants, reproducible comparisons |
| `evaluation` | benchmarking, regression checks, metrics, error/slice analysis |
| `training` | generic model training and recovery |
| `distributed-training` | multi-GPU or multi-node execution |
| `hyperparameter-optimization` | systematic tuning under a defined budget |
| `inference` | batch/online prediction, latency and memory validation |
| `mlops` | artifact lineage, promotion, rollback, durable tracking |

LLM and Vision domains inherit these lifecycle Skills and add domain/task-specific Skills.
