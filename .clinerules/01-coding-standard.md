# codingStandard

Follow `AGENTS.md`, `LLM/AGENT.md`, `LLM/SKILL.md`, and `LLM/ENVIRONMENT.md`.

Detect and measure the real project environment before coding. Optimize runtime settings from measured CPU, RAM, GPU, VRAM, accelerator, Python/runtime, and workload. Run a Memory Smoke Test before long training. After Environment Lock, remove unused platform/device branches unless multi-platform support is intentional.

Use validation metrics, Early Stopping, best checkpoint, resume support, controlled ablation studies, and reproducibility/resource metadata for training work.
